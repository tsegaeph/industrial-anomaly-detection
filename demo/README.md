PatchCore anomaly detection and localization on 7 MVTec AD categories, trained on normal images only.
Pick the product category, upload an image, get a verdict, anomaly score and heatmap.

Code and evaluation: https://github.com/tsegaeph/industrial-anomaly-detection

Dataset: MVTec AD, Bergmann et al., CC BY-NC-SA 4.0 (non-commercial use only).
